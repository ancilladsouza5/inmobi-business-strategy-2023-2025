# InMobi Group: Strategic Business Analysis (2023–2025)

## 📌 Project Overview
An in-depth strategic evaluation of InMobi Group's transition from a mobile-first programmatic advertising network to an experience-first content and commerce ecosystem. This project analyzes how InMobi leverages its dual B2B enterprise engine and B2C lock-screen layer (Glance) to capture consumer intent within compressed attention spans.

## 🎯 The AIDA Framework (Marketing Funnel Analysis)

![AIDA Model](Aida%20Model%20-%20InMobi.png)

### 1. Attention
* **Surface Zero Visibility:** Bypasses typical mobile friction by triggering the second a smartphone screen lights up.
* **Premium Visual Real Estate:** Replaces static wallpapers with dynamic, full-screen interactive cards, live media, and high-definition creator streams.
* **Frictionless Real Estate:** Reaches users organically within their primary 8-second attention window before they navigate away to a dedicated app.

### 2. Interest
* **Glance AI Personalization:** Uses historical contextual clues and real-time interest profiles to match user behavior instantly without manual search inputs.
* **Targeted Content Verticals:** Serves immediate value across prominent buckets, primarily driven by **National News (21%)**, **Sports Content (17%)**, and **Entertainment (12%)**.

### 3. Desire
* **Interactive Formats:** Transitions passive viewpoints into active interest utilizing interactive playable casual games (via Nostra) and immersive "Hyperlive" creator streams (via Roposo).
* **Festive & Contextual Triggers:** Capitalizes on peak consumer behavior metrics (e.g., during the Indian festive season, where data shows **83% of consumers stay active online while physically inside retail stores**).

### 4. Action
* **One-Click Checkout:** Eradicates traditional multi-step application redirection paths, keeping the path-to-purchase native to the active window.
* **Measurable Conversion Lifts:** Yields substantial real-world performance increases, such as a **+204% Growth Lift for Quick-Commerce ads** and a **+202% Growth Lift for E-Commerce ads** by serving transactional capabilities directly onto standby screens.
